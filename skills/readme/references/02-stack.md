# Referência — Seção 2: Stack Tecnológica

A seção de tecnologias deve ser agrupada por responsabilidade, não apenas como lista solta.

Os grupos (Backend, Frontend, Qualidade & CI) são exemplos. Use apenas os grupos relevantes ao stack real detectado — se o projeto não tiver frontend, por exemplo, não inclua esse grupo.
